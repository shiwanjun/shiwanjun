## 工作方式 / How I Work

- **本地优先。** 数据留在自己机器上，能只读就不写入。
- **确认门。** AI 负责执行，关键步骤停下来等人拍板。
- **拆解学习。** 把别人验证过的实现拆开看，只留下能复用的部分。
- **少展示。** 宁可空着，也不摆还没验证过的东西。
